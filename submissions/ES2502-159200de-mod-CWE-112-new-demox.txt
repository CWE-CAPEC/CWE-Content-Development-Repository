NAME: CWE-112 modification new demonstrative example

DESCRIPTION:

I want to suggest the below code for PHP language for the given
description.

Demonstrative Examples

````
$xmlFile = $_GET['file'];
$xml = simplexml_load_file($xmlFile);
echo $xml->asXML();
````

The above PHP code is vulnerable because it directly loads an XML file from
user input without validating its structure against a schema (XSD) or a
Document Type Definition (DTD). This lack of validation allows an attacker
to exploit XML External Entity (XXE) Injection, potentially accessing local
files or executing arbitrary requests on the server. Additionally, improper
handling of the file parameter can lead to file inclusion vulnerabilities,
allowing an attacker to load unexpected or malicious files from the server.


DEMONSTRATIVE EXAMPLES:


INTRO TEXT:

The following PHP code receives XML content from an HTTP request body,
loads the XML content into a PHP SimpleXMLElement Object, and prints
the results back to the user.

BAD CODE:
LANGUAGE: PHP

$xmlContent = file_get_contents('php://input');

if (empty($xmlContent)) {
    http_response_code(400);
    exit('No XML content received.');
}

$xml = simplexml_load_string($xmlContent, 'SimpleXMLElement');

echo $xml->asXML();

EXPLANATORY TEXT:

The above PHP code is vulnerable because it directly loads XML from
user-controlled input. It might assume that the XML is already
compliant with the schema. According to PHP documentation,
simplexml_load_string() only assumes a "well-formed XML
string". [REF-XXX]. So, the code does not actually validate its
structure against a schema (XSD) or a Document Type Definition (DTD).

If the XML does not comply with the expected schema, this lack of
validation could result in the application processing and handling
malformed or unexpected data.

A separate validation step can ensure that any provided data is valid
with respect to the expected XSD/DTD, to address CWE-112.


GOOD CODE:
LANGUAGE: PHP

$xmlContent = file_get_contents('php://input');

// We skip a check that $xmlContent is empty

// Disable external entity loading to prevent XXE
libxml_disable_entity_loader(true);
libxml_use_internal_errors(true);

$dom = new DOMDocument();
$dom->loadXML($xmlString, LIBXML_NONET);

if (!$dom->schemaValidate('/xml/schema.xsd')) {
   http_response_code(400);
   exit('Invalid XML file.');
}

echo $dom->saveXML();


EXPLANATORY TEXT:

Note that the validation step in this code could be inefficient if it
is only applied to inherently trusted files, but there are some
scenarios in which an application must accept externally-submitted
XML. In such cases, the schema validation could occur at an earlier
step.
